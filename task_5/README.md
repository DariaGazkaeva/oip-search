# Task 5. Векторный поиск

Скрипты на Python для векторного поиска.

## Участники
- 11-101 Калимуллин Ильяс  
- 11-101 Газкаева Дарья

## Запуск
### 1. Установите зависимости.

Для этого рекомендуем сначала создать виртуальное окружение
```bash
python -m venv .venv
source .venv/bin/activate
```
Если на `Windows`, то 
```
python -m venv .venv
.\.venv\Scripts\activate
```

Далее установите зависимости
```bash
pip install -r requirements.txt
```

### 2. Запуск скрипта

```python
python vector_search.py <tfidf_dir> <index_file>
```
Необязательные аргументы:
- `tfidf_dir` — путь до директории, где лежат посчитанные TF-IDF для всех документов (используется вариант с леммами)
**Важно**: файлы с леммами должны называться в формате `lemmas_{номер}.txt`.
Значение по умолчанию — `../task_4/results`. Чтобы пропустить, можно написать `-`
- `index_file` — путь до файла с индексом. Значение по умолчанию — `../task_1/results/index.txt`
